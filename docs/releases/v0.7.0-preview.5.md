RookStudio's fifth preview answers its first reports and makes the Chess space sturdier. A failure is now said on its
page, in plain words, with the button that repairs it: link Lichess again, try again once Lichess's pause is over, open
the folder of a file that could not be written, check a damaged database, choose an engine. A damaged database or
profile file no longer closes the program, and a game whose engine crashes always ends.

## What testers reported

- In a tournament, a Polyglot book's lines are now played from the initial position, and their moves are in the games'
  PGN, marked {book}, as with a PGN book; the tournament's Openings tab names these openings. A participant's own book
  now counts these moves in its depth. A tournament started with an earlier preview goes on with the positions it was
  given.
- The Linux and Windows builds run again on x86-64 processors of 2009 and later (x86-64-v2): the Linux build of
  preview 4 asked for AVX2.

## Errors that say what to do

- A failure in the Chess space is said where it happens, with the action that repairs it when there is one:
  - *Link Lichess again…* when the token was revoked or has expired, or *Allow reading studies…* and the like when the
    account was linked without the permission a page needs: lichess.org opens in your browser, and nothing is sent
    before you agree there;
  - *Try again in 0:42* when Lichess asked for a pause after too many requests: a click waits for the end of the
    pause, and nothing is sent before;
  - *Open the folder* when a file could not be written, its path in the tooltip;
  - *Check the database…* when a file of a database is damaged, which opens the database's care at its checks;
  - *Choose an engine…* when no engine is there to analyse;
  - *Register it again* when Lichess no longer knows your external engine.
- Lichess's failures are told apart: no connection, a token refused, a permission missing, a pause asked, a game, a
  study, a player or a round that does not exist. A pause lasts at least a minute, longer when Lichess asks for it, and
  what waited for it (the arena strip, the tablebases, an ending played against the tables) asks again by itself once
  it is over.
- When the engine of the background reviews of your mistakes is removed, they go on with the Board's analysis engine,
  or say there is none and start again by themselves once there is one; before, they waited until you cancelled them.

## Sturdier

- A damaged opening tree no longer closes RookStudio: the Tree tab, the questions, an engine's openings drawn from your
  databases and a repertoire's coverage leave it out and say so.
- A game damaged since its import is marked as such in the game list.
- A profile file with something unexpected in it (edited by hand, cut short) no longer stops RookStudio at launch: what
  cannot be read is set aside and said, and the file as it was is kept beside it.
- A database error during a task (a full disk, a damaged file, another program writing to the database) is said on its
  page instead of ending the program.
- The window no longer freezes while a database commits or a background task ends, and closing RookStudio no longer
  waits for a pause Lichess asked for.
- A game whose engine crashes now ends at once, even when an engine started at the same moment by another game keeps
  its output open; before, such a game could wait for ever. A game you end by hand ends the same way.
- A review stopped at the end of its last pass and resumed later no longer searches a third time.
- Ctrl+K offers to resume a tournament only when that can be done, and Ctrl+F on the databases' shelf searches the
  selected database.

## Security

- The Lichess link ignores an answer that does not carry the state of the question it answers.
- The file names a remote machine lists are copied back only when they stay inside the tournament's folder (from
  fastchess-gui).
- The assistant's runtime, llama.cpp, is updated with the fixes of two vulnerabilities, one with a crafted model file,
  the other with a grammar.

## Languages

- What is new comes in the eight languages of the interface and of the guide.
